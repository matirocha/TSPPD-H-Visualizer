# Reglas de Auditoría y Automatización con Playwright

- **Auditoría Visual:** Utilizar Playwright CLI para verificar visualmente páginas web, tomar capturas de pantalla de la interfaz (`playwright screenshot`) y validar responsividad en resoluciones móvil y escritorio.
- **Eficiencia de Tokens:** Usar los comandos directos de Playwright CLI en lugar de inspecciones DOM masivas para optimizar el consumo de tokens del agente.
- **Verificación de Enlaces y Botones:** Ejecutar pruebas de navegación, clicks y formularios automáticos cuando el usuario solicite validar la funcionalidad del frontend.
