# Reglas Consolidadas para .agents/rules

## Activación Automática: Creación y Edición de HTML y Frontend

Siempre que se pida crear o modificar un archivo HTML, interfaz web o componente visual:

1. **Tasteskill:** Aplicar las directrices de diseño anti-slop, fuentes de alta gama (Geist/Inter), calibración de varianza visual y evitar clichés de IA.
2. **shadcn/ui:** Utilizar tokens y componentes estilo shadcn (paleta Zinc dark mode, bordes `border-zinc-800`, botones táctiles, radios `rounded-xl` / `rounded-2xl`).
3. **Framer Motion / Motion:** Incorporar animaciones suaves basadas en físicas de resorte (`springs`), efectos táctiles hover/tap y entradas escalonadas.
4. **21st.dev:** Implementar bloques de Design Engineering prémium (Spotlight cards con seguimiento de cursor, Bento Grids asimétricas, iluminación ambiental difusa).
